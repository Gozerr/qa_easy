# Дорожная карта QA на пальцах

Статус после аудита: 10 ноября 2026. Отмечаем только работающие сценарии, не карточки-заглушки.

## 1. Фундамент приложения

- [x] Аудит кода и основных маршрутов приложения.
- [x] Разделы построены на Vue Router, общие прогресс и тема доступны через composable.
- [x] Локальная схема прогресса версионируется и мигрирует между версиями.
- [~] XP/ответы подтверждаются Supabase в Telegram; браузерный режим остаётся локальным и недоверенным.
- [~] Достижения вычисляются из прогресса и сохраняются локально; дата открытия пишется для новых переходов после обновления.
- [x] Результаты тестов и пользовательский прогресс сохраняются между открытиями.

## 2. Полноценная Академия QA

- [~] 10 модулей, 50 содержательных уроков и общий контрольный вопрос в конце каждого модуля; расширены риск-анализ, тест-дизайн, HTTP, SQL-транзакции, интеграции, автоматизация и релизная готовность.
- [~] Junior–Middle программа стала шире, но нужны более глубокие автоматизация, API security и практические сквозные проекты.
- [x] У каждого из 50 уроков есть обязательная форма практики с условием, шагами и ожидаемым результатом; ответы сохраняются локально и сверяются с примером и типичной ошибкой.
- [x] Контроль знаний по имеющемуся банку вопросов.
- [x] Карта навыков по 10 направлениям с уровнями Junior/Middle и долей изученных уроков.

## 3. Игровые активности

- [~] «Найди багулю» — есть банк вопросов и сценариев; расширенная серия расследований ещё нужна.
- [~] QA Detective: реализовано первое ветвящееся расследование с логами, гипотезой, планом тестов и итоговым отчётом; нужны дополнительные дела.
- [~] Конструктор тест-кейсов оценивает четыре класса покрытия; нужны сценарии для других функций.
- [~] Bug Report Challenge проверяет основные поля и воспроизводимость; нужны дополнительные дефекты и уровни сложности.
- [x] SQL Lab исполняет безопасный поднабор SELECT над учебными таблицами, включая INNER/LEFT JOIN, WHERE, GROUP BY, COUNT/SUM/AVG, ORDER BY и LIMIT; запросы проверяются на фиксированных ожидаемых наборах. HAVING и вложенные запросы пока не поддерживаются.
- [x] API Lab проверяет платёжную согласованность, пагинацию, безопасный контракт ошибок, идемпотентность платежа, различие 401/403 без утечки данных и повторы webhook с однократным применением события.

## 4. Геймификация

- [x] XP, уровни, серии активности и 34 достижения с коллекцией.
- [~] QA Daily даёт одно ежедневное задание; календарь показывает локальные выполнения, набор ежедневных активностей пока один.
- [~] Три недельные миссии и однократное серверное начисление XP работают через Supabase; миграция и Edge Function развернуты, полный сценарий нужно проверить в Telegram.
- [~] Экран истории XP и локальное хранение ответов готовы; серверная история формируется RPC из подтверждённых ответов и недельных наград. Требуется финальный проход в Telegram.

## 5. Соревнования и социальная часть

- [x] Опциональный серверный рейтинг с псевдонимом и аватаром.
- [~] QA Arena: 10-вопросное испытание, проверенная отправка точности в серверную таблицу месяца и приватность через opt-in рейтинга; миграции и Edge Function развернуты, нужен проход в подтверждённой Telegram-сессии.
- [~] Месячные сезоны включают три тематических марафона и отдельные рейтинги по категориям; SQL/RPC и Edge Function развернуты. Сравнение точности по трём широким направлениям работает за серверным opt-in; среднее скрыто при группе меньше пяти. Сравнение всех десяти учебных модулей ещё не сделано.

## 6. Полировка и запуск

- [x] Единая светлая и тёмная темы, адаптация к мобильным экранам и safe areas.
- [x] Маскот, Telegram-аватар и совместимость с Telegram Mini App.
- [x] Unit/E2E-проверки критических сценариев и границ viewport.
- [~] CSP, RLS и серверная проверка ответов защищают рейтинг, миссии, QA Arena, тематические марафоны и сравнение навыков; обычные игровые редакторы остаются локальными и не начисляют рейтинговый XP.
- [x] Разделить экраны по маршрутам; главный JS bundle уменьшен примерно с 580 kB до 389 kB (114 kB gzip).
